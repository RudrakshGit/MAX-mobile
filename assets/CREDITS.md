# Asset Credits

- **Doodle Icons**: Hand-drawn icon pack by Khushmeen Sidhu (https://khushmeen.com/icons.html), licensed under Creative Commons Zero (CC0 1.0 Universal).
- **Paper Grain**: Procedurally generated 128x128 Gaussian noise tile (`assets/paper-grain.png`).
- **MAX Character**: Original mascot design supplied by repository owner (`rough/files/MAX-design/max_design.png`), traced via potrace (`assets/max/max-traced.svg`) and rigged into parametric React Native SVG components with Reanimated transitions.
- **Student Profile Avatars**: Open Peeps character illustration library by Pablo Stanley (https://openpeeps.com), licensed under Creative Commons Zero (CC0 1.0 Universal).
- **MAX's world card scenes** (since M16, 7 Nov 2026): drawn in code from MAX's own parts and simple props (`src/components/scenes/`), by project team Group E-G18. They replaced the earlier hand-drawn figures.
- **Ambient Sounds**: Procedurally synthesized white, pink, and brown noise loops generated via FFmpeg `anoisesrc` (no third-party copyright).
- **Focus bell** (`assets/sounds/bell.m4a`): three sine tones (660/990/1320 Hz) with an exponential fade, generated with FFmpeg `sine` (no third-party copyright).
