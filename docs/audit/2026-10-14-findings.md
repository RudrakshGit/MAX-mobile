## Improvements to add (beyond the flaws)
Ordered by value for the stated goal (a safe, light, hand-drawn student app). None of these is built yet.

1. **One safety function for every text surface.** `assessText(text)` = regex ∪ model read ∪ safeguard, used by chat, journal save, voice transcript and check-in free text; always returns a result and, when `crisis`, shows the crisis card *before* navigating away. Pair with a 150-phrase golden set that is **not** the training set (English, Hinglish, Hindi-in-Devanagari).
2. **Fail closed when the model is down.** If the read call fails, regex "none" should still trigger the safeguard check for messages above N words, or show a soft "if today is heavy, here are helplines" line.
3. **Honest consent screen** that lists only what exists today, with separate optional toggles (AI journal tags, voice-to-text, campus pulse). Re-ask when M11 ships.
4. **Fix the instruments from the official sources (Claude-owned):** SCI, SAPS, O*NET Mini-IP item lists; keep invented bands out (show raw scores with the published cut-offs only); add a `verified: { by, on, source }` field per instrument and a unit test that fails if it is missing.
5. **Calming motion budget.** Make FloatingMax static (no loops) and animate only on tap; render the boil as a precomputed 3-frame sprite swap instead of 125 ms `setState` over an 830-line SVG; drop to a single `useAnimatedProps` clock. Then re-measure janky frames on a **release** build and write the numbers in `QA-REPORT.md`.
6. **Floating MAX placement:** hide on onboarding, test question screens, Settings, lessons while reading; allow dragging to dismiss per screen; keep ≥ 56 dp away from list chevrons.
7. **Help everywhere:** put the Help pill in the shared `Screen` header so every pushed screen has it (F23).
8. **Replace `Alert.alert`** with one themed sketch dialog component (F28).
9. **Mood calendar:** tapping a day opens check-in for that date (past days only), hide "+" on future days (F38).
10. **Course trust:** add "Draft — reviewed by: pending" chip to every lesson until a reviewer signs; replace non-citable sources with real papers/books or remove the claim (F30–F31).
11. **Onboarding rebuild (3 screens):** (1) MAX waves + one-line promise + Help is one tap; (2) name + avatar pick (one screen, both optional); (3) consent with 3 plain-language toggles and a "Do first check-in now" button that lands on Home with the check-in card focused. Dark/Light choice shown here.
12. **Content depth for India:** more Hindi/Hinglish videos and lessons; add the verified Hindi-language helpline list (state-wise Tele-MANAS languages) to Help.
13. **Insight quality:** feed real numbers (7-day mood trend, sleep delta, phone minutes) into the daily insight prompt and show one concrete suggestion with a deep link to the matching tool (F14).
14. **Release readiness:** exclude `/dev/max` and the Expo dev menu from production, verify `allowBackup=false` and the usage-stats permission text in the built APK, and run the 15-test content check in CI.
